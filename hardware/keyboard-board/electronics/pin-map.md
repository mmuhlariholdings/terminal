# Keyboard board: RP2040 pin map and connector pinouts

Generated by `hardware/keyboard-board/electronics/generate_schematic.py` (Rev A). Do not edit by hand.
`firmware/keyboard-board/src/board.h` must match this table: the generator checks it and fails if it does not.
The bench build (a plain Raspberry Pi Pico) uses the same GPIO numbers; GPIO 23, 24, 25 and 29 are not on the Pico's
header (SMPS mode, VBUS sense, LED, VSYS/3) and only carry power-management signals.

## Keyboard matrix (from the BBQ20KBD and its firmware i2c_puppet)

Rows are inputs with pull-ups; one column at a time is driven low. Column 7 is a single key read directly.

| Row \ Column | COL1 (GPIO 8) | COL2 (9) | COL3 (14) | COL4 (13) | COL5 (12) | COL6 (11) |
|---|---|---|---|---|---|---|
| ROW1 (GPIO 1) | trackpad click | W 1 | G / | S 4 | L " | H : |
| ROW2 (GPIO 2) |  | Q # | R 3 | E 2 | O + | U _ |
| ROW3 (GPIO 3) | Call key (LEFT1) | microphone key 0 | F 6 | Left Shift | K ' | J ; |
| ROW4 (GPIO 4) |  | Space | C 9 | Z 7 | M . | N , |
| ROW5 (GPIO 5) | BlackBerry key (LEFT2) | Sym | T ( | D 5 | I - | Y ) |
| ROW6 (GPIO 6) | Back key (RIGHT1) | Alt | V ? | X 8 | speaker key $ | B ! |
| ROW7 (GPIO 7) |  | A * | Right Shift | P @ | Backspace | Enter |

COL7 (GPIO 10): the End / hang-up key (RIGHT2), read directly (low = pressed).
Key legends are base letter then the printed Alt symbol. The identity of the four nav keys (Call, BlackBerry, Back,
End) is from the BBQ20KBD documentation and is **unverified on our hardware**.
